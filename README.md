## 👨‍💻 关于我

- 📱 主力 **Android / Kotlin** 开发，关注 Jetpack Compose、MVVM / MVI 架构与蓝牙音频调试
- 🛠️ 喜欢写顺手的小工具：网络诊断、文件处理、服务器监控，桌面端用 Tauri + Rust、C# / .NET 和 Java Swing
- 🤖 用 GitHub Actions + 大模型做无服务器的自动化小机器人，消息都推到钉钉
- 📦 做的工具都会打包发版，数据尽量只留在本机
- 🐳 折腾自托管与 DevOps：Docker Compose、Linux、VPS、Cloudflare
- 🌱 持续学习中，也在探索 AI 工具在日常开发中的落地
- 💬 欢迎通过 [Issues](https://github.com/kekemao00/kekemao00/issues) 交流想法

## 🔭 最近在做

**📱 Android**

- 🎧 [**BtLogger**](https://github.com/kekemao00/android-bt-logger)：后台记录蓝牙耳机、音箱、车机的连接断开、编解码、电量和音量，把“偶现断连”变成可追溯的数据（Kotlin + Jetpack Compose）

**🖥️ 桌面工具**

- 📅 [**刻忆 Daymark**](https://github.com/kekemao00/daymark)：生日、纪念日只记一次，农历自动换算，提前 1 个月、1 周和当天弹出 Windows 通知（Tauri 2 + Rust + React）
- 🌐 [**IP Tool**](https://github.com/kekemao00/ip-tool)：一键切换网卡 IP / DNS，分层诊断断网出在哪一环，还能让 git、npm 这些命令行工具跟着系统代理走（C# / .NET）
- 🧰 [**File Toolkit 文件全能王**](https://github.com/kekemao00/FileToolkit)：本地处理 PDF、图片、音视频与压缩包的跨平台工具箱，还能把各种文档转成 AI 好读的 Markdown，文件不出本机（Python + Flet）
- 📒 [**ContactManager**](https://github.com/kekemao00/contact-manager-swing)：纯本地通讯录，按行业分类、支持分享码和二维码。起因是饭局上一句“这有啥难的，我给你做一个”，第二天花 2 小时兑现（Java Swing + SQLite）

**🤖 自动化机器人**

- 📰 [**digest-bot**](https://github.com/kekemao00/digest-bot)：每天早晚把精选资讯推送到钉钉群，大模型写中文摘要并控制领域占比，全程跑在 GitHub Actions 上（Python）
- 📡 [**vps_monitor**](https://github.com/kekemao00/vps_monitor)：VPS 流量四级预警和用量预测，在钉钉群里 @机器人 就能查流量（Python）
